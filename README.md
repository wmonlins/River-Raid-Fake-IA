# River Raid Rápido

Um jogo arcade inspirado nos clássicos de navegação e combate, desenvolvido por meio de **vibe coding com inteligência artificial**.

O projeto foi criado a partir de ideias, instruções em linguagem natural e iterações com IA, com foco em transformar uma ideia em uma experiência jogável, explorando mecânicas de jogo, interação, áudio e recursos multiplayer.

### Funcionalidades

- Jogabilidade arcade com movimentação, disparos e obstáculos.
- Combustível, armas especiais, escudo e sistema de pontuação.
- Progressão de níveis, ambientes variados e batalhas contra chefes.
- Efeitos visuais, efeitos sonoros e música sintetizada.
- Robô para jogar automaticamente.
- Recordes locais e ranking online.
- Modo cooperativo online com salas por código.
- Controles por teclado e interface adaptada para dispositivos com tela sensível ao toque.

### Tecnologias

- HTML5
- CSS3
- JavaScript
- Canvas API
- Web Audio API
- Firebase Realtime Database

### Desenvolvimento com IA

Este projeto foi desenvolvido com uma abordagem de **vibe coding**, utilizando inteligência artificial como principal ferramenta de geração e evolução do código a partir de instruções em linguagem natural.

O objetivo foi explorar o desenvolvimento de jogos assistido por IA, transformar ideias em funcionalidades concretas e experimentar a construção de uma aplicação jogável sem depender da escrita manual tradicional de código.

O uso de IA faz parte da proposta do projeto e é apresentado de forma transparente.

### Como executar

1. Baixe ou clone este repositório.
2. Abra o arquivo `index.html` em um navegador moderno.
3. Utilize as setas ou as teclas WASD para movimentar a aeronave e a barra de espaço para atirar.

O ranking online e o modo cooperativo dependem da disponibilidade e da configuração do Firebase utilizado pelo projeto.

### Objetivo

Projeto pessoal e experimental, criado para explorar as possibilidades do desenvolvimento de jogos com inteligência artificial.

Sugestões, testes e contribuições são bem-vindos.
